# EHDSレポート 本質的ファクトチェック方法論

作成日: 2025-08-13
目的: 形式的な修正ではなく、実質的な価値を提供するファクトチェックの実施

## ファクトチェックのベストプラクティス（調査結果）

### 1. SIFTメソッドの適用

**S - Stop（立ち止まる）**
- 強い感情を引き起こす主張は特に慎重に検証
- EHDSの経済効果や日本への影響などインパクトの大きい数値

**I - Investigate the Source（情報源の調査）**
- 一次資料への遡及
- EU公式文書（EUR-Lex、Official Journal）を優先

**F - Find Better Coverage（より良い情報源を探す）**
- 複数の独立した情報源での確認
- 専門機関による分析レポートの参照

**T - Trace Claims（主張の追跡）**
- ネットワーク分析：他の専門家の評価を確認
- 時系列での変化を追跡

### 2. 情報源の信頼性階層

**Tier 1: 最高信頼度**
- EU公式文書（Regulation、Directive、Decision）
- 欧州委員会公式レポート
- 加盟国政府公式発表

**Tier 2: 高信頼度**
- 査読済み学術論文
- 国際機関レポート（WHO、OECD）
- 大手コンサルティング企業の公式分析

**Tier 3: 中信頼度**
- 業界団体レポート
- ニュースメディア報道
- 専門家ブログ・解説

## EHDSレポートの本質的検証項目（再定義）

### A. 政策の実現可能性に関する検証

1. **実装タイムラインの現実性**
   - 問題：「2029年に全加盟国で運用開始」は技術的・組織的に可能か？
   - 検証方法：過去のEU規制（GDPR等）の実装遅延事例との比較
   - 重要性：日本の対応スケジュール策定の基礎

2. **予算規模の妥当性**
   - 問題：EU投資50億ユーロで目標達成可能か？
   - 検証方法：類似プロジェクト（エストニアのX-Road等）のコスト分析
   - 重要性：日本の投資規模見積もりの参考

3. **各国実装の進捗差**
   - 問題：先行国と遅延国の格差がもたらす影響
   - 検証方法：2025年8月時点の各国状況の一次資料確認
   - 重要性：日本の段階的実装戦略への示唆

### B. 技術仕様の実装可能性

1. **相互運用性の技術的課題**
   - 問題：FHIR R4/R5の混在、レガシーシステムとの統合
   - 検証方法：HL7 Europe実装ガイドと現場報告の照合
   - 重要性：日本の標準化戦略への影響

2. **セキュリティ要件の実現性**
   - 問題：連合学習、プライバシー保護技術の成熟度
   - 検証方法：EDPS技術文書と実装事例の比較
   - 重要性：日本のセキュリティ基準策定

3. **データ品質保証メカニズム**
   - 問題：異なる医療システム間でのデータ品質維持
   - 検証方法：EEHRxF実装報告の分析
   - 重要性：日本のデータガバナンス設計

### C. 経済効果の検証可能性

1. **医療費削減効果の算出根拠**
   - 問題：「10年で110億ユーロ削減」の前提条件
   - 検証方法：EC Impact Assessmentの詳細分析
   - 重要性：日本での費用対効果分析の基礎

2. **デジタルヘルス市場成長予測**
   - 問題：CAGR 12.4%の持続可能性
   - 検証方法：複数の市場調査機関データの比較
   - 重要性：日本企業の投資判断材料

3. **ROI実現までの期間**
   - 問題：初期投資回収の現実的タイムライン
   - 検証方法：フィンランド等先行事例の財務分析
   - 重要性：日本の段階的投資計画

## 実施手順（高速化のための並列処理）

```
並列実行:
- EUR-Lexでの法的文書確認
- EC公式サイトでの最新情報収集
- 学術データベースでの引用確認
```

```
並列実行:
- 技術仕様の実装報告確認
- 各国実装状況の公式発表確認
- 経済分析の前提条件確認
```

### Phase 3: 統合分析（30分）
```
- 矛盾点の特定
- 信頼度スコアリング
- 改善提案の作成
```

## 検証の優先順位（実質的影響度順）

### 最優先（日本の意思決定に直接影響）
1. **EHDSの段階的実装の成功要因**
   - フィンランド成功の再現可能性
   - ドイツ・フランスの課題と対策

2. **技術標準の選択根拠**
   - FHIR採用の必然性
   - 日本の既存システムとの互換性

3. **投資対効果の実証データ**
   - 先行投資国のROI実績
   - 失敗事例とその要因

### 高優先（戦略策定の基礎情報）
4. **ガバナンス体制の有効性**
   - HDAB設置の実効性
   - 罰則規定の執行実績

5. **プライバシー保護の実装方法**
   - GDPR準拠の具体的手法
   - 患者同意管理の実態

6. **人材育成プログラムの効果**
   - 必要スキルセットの定義
   - 育成期間とコスト

### 中優先（長期計画の参考情報）
7. **産業界への影響**
   - 医療機器メーカーの対応
   - スタートアップの参入機会

8. **国際連携の可能性**
   - 第三国参加の条件
   - アジア太平洋地域との連携

## アクションアイテム

### 即時実施事項
1. **一次資料リストの作成**
   - EUR-Lex文書番号の整理
   - EC公式レポートのURL確認
   - 各国政府発表のアーカイブ

2. **検証チェックリストの作成**
   - 各項目の検証ステータス管理
   - 信頼度スコアの記録
   - 更新履歴の追跡

3. **継続的モニタリング体制**
   - 四半期ごとの更新確認
   - 新規発表の即時反映
   - 予測vs実績の追跡

## 成果物

1. **検証済みファクトシート**
   - 各主張の信頼度評価
   - 根拠資料へのリンク
   - 最終確認日時

2. **不確実性マトリクス**
   - 確定事項vs推測事項の分類
   - リスク評価
   - 代替シナリオ

3. **更新管理ログ**
   - 変更履歴
   - 影響範囲
   - 次回確認予定
