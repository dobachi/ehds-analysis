# 引用・出典管理方針

## 基本原則

### 1. ハルシネーション防止の徹底
- **原則**: すべての事実記述には出典を明記する
- **例外**: 一般的な定義や広く知られた事実のみ出典省略可
- **疑義がある場合**: 出典を示すか、推測・考察である旨を明記

### 2. 情報の分類と表記

#### 事実情報
```markdown
【事実】
EHDSは2022年5月3日に欧州委員会により正式提案された^[1]^。

[1] European Commission. (2022). Proposal for a Regulation on the European Health Data Space. COM(2022) 197 final.
```

#### 推測・分析
```markdown
【分析】
フィンランドの早期実装成功は、国民IDシステムの整備と高いデジタルリテラシーが要因と考えられる。
（筆者による分析）
```

#### 不確実な情報
```markdown
【未確認情報】
2025年前半の最終採択が予定されているが、政治的要因により遅延の可能性がある。
（複数の業界レポートによる推測、公式確認なし）
```

## 出典の信頼性レベル

### レベル1：最高信頼度
- EU公式文書（規則、指令、通達）
- 各国政府公式発表
- 国際機関レポート（WHO、OECD等）

### レベル2：高信頼度
- 査読付き学術論文
- 大手コンサルティング会社レポート（PwC、Deloitte等）
- 業界団体公式文書

### レベル3：中信頼度
- 専門メディア記事
- 企業プレスリリース
- カンファレンス発表資料

### レベル4：参考情報
- ブログ記事
- SNS投稿
- 非公式インタビュー

**使用方針**: レベル1-2を基本とし、レベル3-4は補足情報として使用

## 引用形式

### 文中引用
```markdown
欧州委員会（2022）によれば、EHDSは「患者の権利強化と産業振興の両立」を目指している[1]。
```

### 脚注形式
```markdown
EHDSの実装には約500億ユーロの投資が必要とされる^[PwC, 2023]^。
```

### ブロック引用
```markdown
> "The European Health Data Space is a health specific ecosystem comprising rules, 
> common standards and practices, infrastructures and a governance framework"
> 
> — European Commission, EHDS Proposal (2022), p.1
```

## 実装ガイドライン

### レポート作成時のチェックリスト

#### 執筆時
- [ ] 各段落の事実記述に出典があるか確認
- [ ] 数値データには必ず出典を付記
- [ ] 日付・期限は公式文書で確認
- [ ] 引用と考察を明確に区別

#### レビュー時
- [ ] 出典のURLが有効か確認
- [ ] 引用の正確性を原文と照合
- [ ] 出典の発行日が最新か確認
- [ ] 相互参照の整合性チェック

### 出典管理ツール

#### 推奨ツール
- **Zotero**: 文献管理（無料、9000+引用スタイル対応）
- **Mendeley**: PDFアノテーション機能
- **Notion/Obsidian**: リンク管理

#### ファイル管理
```
sources/
├── official/          # レベル1資料
│   ├── EU/           # EU公式文書
│   └── national/     # 各国政府文書
├── academic/         # レベル2学術資料
├── industry/         # レベル2-3業界資料
└── references.bib    # BibTeX形式の文献リスト
```

## 特殊ケースの扱い

### AIツール使用時
```markdown
【AI支援による要約】
以下は、複数の資料を基にAIツールで要約した内容である：
[要約内容]
参照資料：[1][2][3]
```

### インタビュー情報
```markdown
【インタビュー】
EU関係者へのインタビュー（2025年1月、匿名希望）によれば...
※録音・記録は筆者保管
```

### 翻訳資料
```markdown
【翻訳資料】
原文：[ドイツ語タイトル]
翻訳：筆者による仮訳
注：公式翻訳ではない
```

## 考察・推測の記載方法

### 明示的なマーカー使用
- 「～と考えられる」
- 「～の可能性がある」
- 「筆者の見解では」
- 「推測の域を出ないが」

### セクション分離
```markdown
## 4.1 事実の整理
[出典付きの事実記述]

## 4.2 考察と含意
[筆者による分析・考察]
```

## 更新履歴の管理

### 情報更新時の記載
```markdown
【更新情報】2025年1月8日
- EHDS採択時期を「2024年末」から「2025年前半」に修正
- 出典：Council of the EU Press Release (2024.12.15)
```

### 訂正時の対応
```markdown
【訂正】
前版では「全加盟国で2026年実装」としたが、
正しくは「2026年から段階的実装」である。
```

## 実践例

### 良い例 ✅
```markdown
EHDSの規則案は2022年5月3日に提案され[1]、2024年4月に政治的合意に達した[2]。
実装には各国で2-3年かかると予想される（筆者推定）。

[1] COM(2022) 197 final
[2] Council Press Release, April 2024
```

### 悪い例 ❌
```markdown
EHDSは来年には完全実装される予定で、すべての病院が参加する。
（出典なし、断定的すぎる）
```
