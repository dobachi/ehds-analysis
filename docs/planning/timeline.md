# EHDS実装タイムライン

## 主要マイルストーン時系列

### 2020年以前：基礎構築期

**2016年**
- GDPR採択（2018年5月施行）
- eHealth Network設立強化

**2018年**
- GDPR施行開始
- Digital Single Market戦略本格化

**2019年**
- European Health Data Space構想発表
- MyHealth@EU開発開始

### 2020-2021年：構想具体化期

**2020年2月**
- 欧州データ戦略発表
- EHDSを重要施策として位置づけ

**2020年11月**
- Data Governance Act（DGA）提案

**2021年4月**
- AI規制法案提案
- 医療AIとの連携検討開始

**2021年12月**
- EHDS影響評価実施
- ステークホルダー協議完了

### 2022年：規則提案期

**2022年2月**
- Data Act提案

**2022年5月3日**
- **EHDS規則案正式提案**（COM(2022) 197 final）
- 一次利用・二次利用の枠組み明確化

**2022年6月-12月**
- 各国議会での検討開始
- 産業界からのフィードバック収集

### 2023年：調整・修正期

**2023年3月**
- 欧州議会ENVI・LIBE委員会審議

**2023年6月**
- DGA施行開始

**2023年10月**
- 欧州議会修正案採択
- より強力なデータ保護措置追加

**2023年12月**
- 理事会共通アプローチ合意

### 2024年：最終調整期

**2024年3月**
- 三者協議（トリローグ）開始
- 議会・理事会・委員会の調整

**2024年4月**
- **政治的合意達成**（暫定合意）

**2024年11月**
- 最終文書調整
- 技術的詳細の確定

### 2025年：採択・移行期

**2025年前半**（予定）
- 欧州議会・理事会最終採択
- 官報掲載

**2025年後半**
- 施行開始（採択20日後）
- 各国実装準備期間開始

### 2026-2027年：段階的実装期

**2026年**
- 一次利用システム稼働開始
- MyHealth@EU全加盟国接続目標
- 認証制度運用開始

**2027年**
- 二次利用システム本格稼働
- HealthData@EU運用開始
- データ品質基準完全適用

### 2028-2030年：完全運用期

**2028年**
- 全加盟国での完全実装目標
- 第三国との相互運用性検討

**2029年**
- 初回評価レポート公表
- 必要に応じた規則改正検討

**2030年**
- EHDS完全運用達成目標
- 次期戦略検討開始

## リスクと不確実性

### 遅延リスク要因
1. **政治的要因**
   - 欧州議会選挙（2024年）の影響
   - 各国政権交代

2. **技術的要因**
   - レガシーシステム移行の困難
   - 標準化の遅れ

3. **社会的要因**
   - 市民の受容性
   - 医療従事者の抵抗

4. **経済的要因**
   - 予算制約
   - COVID-19後の財政逼迫

### 加速要因
- パンデミック経験による危機感
- デジタル化投資の増加
- AI活用への期待
