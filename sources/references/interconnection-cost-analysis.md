# 地域医療連携ネットワーク相互接続・標準化改修費用の分析

## 記載内容
「相互接続・標準化対応改修：1地域あたり約5,400万円 × 279地域 = 約150億円」

## 根拠の調査結果

### 1. 直接的な根拠

- **5,400万円という具体的な金額の出典は特定できず**
- 厚生労働省、総務省の公開資料に該当する金額の明記なし

### 2. 類似事例からの推定根拠

#### オンライン資格確認システムの導入費用（参考）

- 病院：事業額上限42.9万円（補助率100%）
- 診療所：事業額上限42.9万円（補助率3/4）
- システム改修費用：25万円〜70万円程度
- ネットワーク構成が複雑な場合は追加費用発生

#### 地域医療介護総合確保基金による支援

- 総務省：平成28年度補正予算20億円
- クラウド型EHR高度化事業として全国16団体へ補助
- 双方向の情報連携実現に向けた改修を支援

#### JMARIレポートからの参考データ

- 平均システム構築費用（累積）：2億5,409万円
- 年間運営予算：1,185万円
- 既存システムの改修は新規構築の20-30%程度が一般的

### 3. 5,400万円の妥当性評価

#### 算出根拠の推定

- 既存システム構築費用（2.54億円）の約20% = 約5,080万円
- これに標準化対応の追加開発を含めると5,400万円は妥当な範囲

#### 改修内容の想定

1. **データ形式の標準化**
   - SS-MIX2からHL7 FHIRへの変換機能
   - 既存データの移行・変換作業
   
2. **API接続機能の実装**
   - RESTful API実装
   - 認証・認可機能の追加
   
3. **セキュリティ強化**
   - ゼロトラストアーキテクチャ対応
   - 暗号化・匿名化機能の高度化

4. **相互運用性の確保**
   - 他地域ネットワークとの接続テスト
   - データマッピング・変換ルール設定

### 4. 総額150億円の妥当性

- 279地域 × 5,400万円 = 150.66億円
- 全国規模での標準化・相互接続実現には妥当な投資規模
- ただし、地域により改修規模に差があることを考慮すべき

### 5. 提言

#### 記載方法の改善案
現在の記載：
```
相互接続・標準化対応改修：1地域あたり約5,400万円 × 279地域 = 約150億円
```

改善案：
```
相互接続・標準化対応改修：既存システム構築費用の約20%程度と想定
（平均構築費用2.54億円の20% = 約5,000万円/地域）× 279地域 = 約140億円
```

または、より柔軟な表現：
```
相互接続・標準化対応改修：地域の規模により1,000万円〜1億円程度
全国279地域での総額：100億円〜200億円程度
```

## 結論

5,400万円という金額は、既存システムの構築費用や類似のシステム改修事例から推定すると妥当な範囲内にある。ただし、具体的な根拠資料が確認できないため、より透明性の高い記載方法への変更を検討することが望ましい。
