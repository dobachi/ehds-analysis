# EHDS Analysis - 欧州健康データ空間分析レポート

**[オンラインで読む](https://dobachi.github.io/ehds-analysis)**

## 概要

このリポジトリは、EHDS（European Health Data Space：欧州健康データ空間）に関する包括的な分析レポートと、日本への政策提言を含むドキュメント群です。

## ドキュメント構成

- **quarto-report/** - Quartoによるレポート本体
- **sources/** - 調査資料・参考文献
- **docs/** - 調査ドキュメント
- **scripts/** - ビルドスクリプト

## ビルド方法

```bash
# セットアップ
./setup.sh

# レポートのビルド
make all
```

詳細は各ディレクトリのREADMEを参照してください。
