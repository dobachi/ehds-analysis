# セキュリティ強化・プライバシー保護費用（800億円）の根拠分析

## 記載内容
- セキュリティ強化・プライバシー保護（約800億円）
  - ゼロトラストアーキテクチャ導入（約300億円）
  - 医療機関向けSOC（Security Operation Center）構築・運用（約200億円）
  - 暗号化・匿名化技術の高度化（約300億円）

## 調査結果

### 1. 実際の政府予算・補助金

#### 医療機関サイバーセキュリティ確保事業（厚生労働省）
- **2024年度補正予算・2025年度予算**：110億円
- 対象：電子カルテシステム導入済みの20床以上の病院（約2,000病院）
- 支援内容：
  - 外部ネットワーク接続の安全性検証・点検
  - オフラインバックアップシステムの構築
- 1病院あたり：約550万円（110億円÷2,000病院）

#### 東京都の例
- 令和7年度医療機関診療情報サイバーセキュリティ対策支援事業
- 医療機関のデジタル化推進とサイバーセキュリティ対策を支援

### 2. ゼロトラストアーキテクチャ導入費用（300億円の検証）

#### 政府の取り組み
- デジタル庁「ゼロトラストアーキテクチャ適用方針」（2022年）
- 金融庁による調査・研究の実施

#### 企業導入事例の実態
- PwC調査（2021年）：実装済み130社
- 効果：期待値を10ポイント以上下回る結果
- 成功要因：外部専門家の活用、長期的な取り組み

#### 構成要素
- ID管理・認証システム
- デバイス管理（EDR）
- ネットワークセグメンテーション
- CASB（Cloud Access Security Broker）
- 多要素認証

**妥当性評価**：
- 全国8,100病院 × 平均3,700万円 = 約300億円
- ただし、段階的導入が現実的（初期は重点病院のみ）

### 3. 医療機関向けSOC構築・運用費用（200億円の検証）

#### 実際のSOCサービス費用
- **CEC SOC**：月額30万円～（PC1,000台あたり）
- **JSOC（ラック社）**：
  - 国内最大規模：約500組織を監視
  - 1日19億件のログ・アラート処理
  - 約300名のセキュリティアナリスト・エンジニア

#### 人材育成コスト（総務省資料）
- SOCスタッフ育成：1人あたり約40万円
- スキル維持：20万円/5年
- 年間賃金：高額

#### 医療機関向けSOC構築シナリオ
- 全国5ブロックにSOC設置
- 各SOC運用費：年間10億円（人件費・システム費）
- 5年間：5ブロック × 10億円/年 × 5年 = 250億円

**妥当性評価**：200億円は5年間の運用費として妥当だが、初期構築費を含めると不足の可能性

### 4. 暗号化・匿名化技術の高度化（300億円の検証）

#### 次世代医療基盤法関連
- 認定事業者（2024年現在）：
  - ライフデータイニシアティブ（LDI）・NTTデータ
  - 日本医師会医療情報管理機構・ICI・日鉄ソリューションズ
  - 匿名加工医療情報利活用推進機構・日立製作所

#### 技術開発の実態
- 匿名加工処理技術の開発
- 仮名加工医療情報の処理技術（2024年4月法改正）
- 公的データベースとの連結技術

#### 認定事業者の運営状況
- LDI代表：「認定が1年以上遅れ、債務状況から脱却」
- 収益化の課題が存在

**妥当性評価**：
- 技術開発：100億円
- システム実装（全国展開）：100億円
- 運用・保守（5年間）：100億円
- 計300億円は大規模だが、全国展開には必要な規模

## 改善提案

### 現在の記載の問題点
1. **根拠不明確**：具体的な積算根拠が示されていない
2. **規模感の乖離**：実際の政府予算（110億円）と提案額（800億円）の差が大きい
3. **実現性**：一度に全額投資は非現実的

### 改善案

#### 案1：段階的導入を明記
```markdown
**セキュリティ強化・プライバシー保護（5年間で400億円）**：
- 第1段階（1-2年）：重点病院への導入（100億円）
  - 基幹病院2,000施設へのサイバーセキュリティ対策
  - 厚労省補助金110億円を活用
- 第2段階（3-5年）：全国展開（300億円）
  - ゼロトラスト段階導入
  - 地域SOC構築（5ブロック）
  - 暗号化・匿名化技術の標準化
```

#### 案2：実績ベースの積算
```markdown
**セキュリティ強化・プライバシー保護**：
- 厚労省サイバーセキュリティ確保事業：110億円（実績）
- 追加セキュリティ投資（民間負担分）：200億円
- 技術開発・標準化：100億円
- 合計：約400億円（5年間）
```

## 結論

提案されている800億円は、理想的な完全実装には必要な規模だが、実際の政府予算や段階的導入の観点から、より現実的な金額（400-500億円/5年）への修正が望ましい。特に、既存の補助金制度との整合性を取り、段階的な導入計画を明記することが重要。
