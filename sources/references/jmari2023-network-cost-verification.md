# 地域医療連携ネットワーク構築費用の根拠調査結果

## 調査対象文献
日本医師会総合政策研究機構「ICTを利用した全国地域医療情報連携ネットワークの概況（2023年度版）」
- Working Paper No.485（2025年6月）
- URL: https://www.jmari.med.or.jp/wp-content/uploads/2025/06/WP485.pdf

## 主要な調査結果

### 1. 構築費用（累積）
PDFのp.50（2.14.1節）より：
- **平均システム構築費用（累積）：2億5,409万1千円**
- 調査対象：189地域
- 中央値：2,500万円
- 最大値：90億5,582万4千円
- 最小値：16万円

### 2. 年間運営予算
調査報告書の概要より：
- **2024年度の平均年間運営予算：1,185万円**

### 3. その他の関連指標
- 全国で稼働している地連NWの平均運用年数：9.3年
- 1地連NWあたりの平均参加施設数：143.0施設
- 1参加施設あたり：163万4,761円
- 1患者あたり：1万2,770円の構築費用

## 本文での記載との差異

### 現在の記載
```
1ネットワークあたりの平均構築費用（累計）は約2.55億円、年間運用費は約1,340万円
```

### 実際のデータ
- 構築費用：2億5,409万1千円 → **記載の「約2.55億円」は妥当**
- 年間運営予算：1,185万円 → **記載の「約1,340万円」は若干の差異あり**

## 推奨される修正

年間運用費について、より正確な値に修正することを推奨：
- 現在：「年間運用費は約1,340万円」
- 修正案：「年間運営予算は約1,185万円」または「年間運営予算は約1,200万円」

## 補足情報

### データの分布について
- 構築費用は地域により大きな差がある（16万円〜90億円超）
- 10億円以上の高額システムは11箇所
- 10億円未満の173地域の平均構築費用は8,335万円
- 「100万円以上〜3,000万円未満」が最も多い（84箇所）

### 対象範囲別の構築費用
- 対象範囲が広い地域ほど構築費用が高い傾向
- 市区町村単位での連携の方が低コスト

### 製品別の構築費用
- 使用する製品により大きな差がみられる
- HumanBridge、ID-Link等の主要製品間でも差異あり

## 調査の信頼性
- 有効回答数：279地域（全国の地域医療連携ネットワーク）
- 調査実施：2024年2月
- 継続調査：2012年度から実施されている定点観測調査
- 回答率：高い回答率を維持

## 結論
日本医師会総合政策研究機構の2023年度調査は、記載されている構築費用「約2.55億円」の根拠として適切である。ただし、年間運用費については「約1,340万円」から「約1,185万円」への修正を検討することが望ましい。
